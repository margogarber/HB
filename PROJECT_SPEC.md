# Поздравления для Виктории — спецификация проекта

Интерактивная мобильная веб-открытка ко дню рождения. Статическое React + Vite приложение (JavaScript, без TypeScript), публикация на GitHub Pages.

## Ограничения

- Полностью статическое: без сервера, БД, API и секретных ключей
- Без React Router — одностраничное последовательное приложение
- Без тяжёлых UI-библиотек; анимации преимущественно на CSS
- `vite.config.js`: `base: '/HB/'` для GitHub Pages project site
- Весь персональный контент редактируется только в `src/data/gameData.js`

## Персонажи и сюжет

- Именинница: **Виктория**, обращение **«Бусинка»**
- Спутник: маленький чёрный шпиц **Филя** — серьёзный, неуклюжий, саркастичный и милый
- Филя передаёт поздравительное письмо после того, как Бусинка пройдёт 6 этапов и соберёт виртуальный букет воспоминаний
- Без проигрыша, жёсткого таймера и возможности застрять
- Целевая длительность: ~7–9 минут

- Mobile-first, ширина контента ≤ 520px, от 320px
- Округлённые карточки, лёгкие тени, тонкие цветочные элементы
- Крупные кнопки, удобное управление пальцем
- Спокойные плавные анимации

## Этапы

| # | Ключ | Описание |
| --- | --- | --- |
| 0 | `intro` | Вступление |
| 1 | `hearts` | Ловля семи сердечек |
| 2 | `findItems` | Поиск четырёх спрятанных предметов |
| 3 | `quiz` | Личная викторина (3 вопроса) |
| 4 | `memory` | Поиск четырёх пар карточек |
| 5 | `puzzle` | Фотопазл 3×3 |
| 6 | `bouquet` | Создание виртуального букета |
| 7 | `letter` | Финальное письмо |

После каждого из этапов 1–6 в индикаторе прогресса появляется новый цветок.

## Фотографии

Пути (папка `public/assets/photos/`):

- `photo1.jpg` … `photo4.jpg` — карточки воспоминаний
- `photo5.jpg` — пазл
- `photo6.jpg` — поиск предметов

Если файла нет — эстетичная градиентная заглушка с номером фото. Приложение не ломается.

## Архитектура

```
src/
  data/gameData.js          — весь персональный контент
  components/               — Intro, Filia, BouquetProgress, StageShell, FinalLetter
  minigames/                — заглушки / механики этапов 1–6
  hooks/useGameProgress.js  — этап + localStorage
  utils/                    — storage, фото-заглушки
```

- Состояние текущего этапа
- Подготовленная структура для `localStorage`
- Единая оболочка этапа (`StageShell`)

### Готово (шаг 2)

- SVG-Филя со состояниями: neutral, happy, thinking, surprised, letter
- Вступительный конверт, карточки, кнопки, модальные реплики (`FiliaModal`)
- Букет-прогресс из шести SVG-цветов
- Переходы этапов, safe-area, prefers-reduced-motion, focus, контраст

### Готово (шаг 3)

- Механика «Ловля сердечек» (7 шт.)
- Механика «Поиск предметов» на photo6 + координаты в gameData

### Готово (шаг 4)

- Карточки воспоминаний (фото ↔ подпись), сетка 2×4, `memoryPairs`
- Фотопазл 3×3 (тап–тап), подсказка, финальная реплика
- Конструктор букета (основной / доп. / лента), SVG-цветы
- Черновики этапов 4–6 и выбор букета в localStorage

### Готово (шаг 5)

- Финальная сцена: конверт → букет → письмо из `finalLetter`
- Настройки: «Начать сначала» с подтверждением
- History API для кнопки «назад»
- Без автозвука, без горизонтального скролла

### Осталось

- Вставить готовое поздравление в `src/data/gameData.js` → поле `finalLetter`
- Реальные фотографии в `public/assets/photos/`
- Включить GitHub Pages: Settings → Pages → Source → GitHub Actions (если ещё не включено)
